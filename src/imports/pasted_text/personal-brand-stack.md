# ⚡ Performance architecture

This is critical.

You want:

**WOW + SPEED**

not:

**WOW + 8-second loading screen.**

Use Next.js's optimization capabilities, lazy-load heavy project media and keep the 3D experience isolated. Next.js is designed for interactive, dynamic applications and provides optimization around things like images, links and fonts. ([Next.js][1])

Also:

* lazy-load Three.js
* don't load 3D on every section
* use compressed WebP/AVIF images
* animate transforms/opacity wherever possible
* avoid huge background videos
* use `prefers-reduced-motion`
* keep the initial JavaScript payload under control
